# AI 协作约定

> 与 AI 编码助手（Claude Code、Cursor、ChatGPT、DeepSeek Harness 等）协作的完整约定。AGENTS.md 第四节只列概要。

---

## 一、协作铁律

1. **动手前先读 AGENTS.md** — 不熟悉项目结构时，先读 AGENTS.md + 相关 docs/
2. **不堆代码到 AGENTS.md** — 代码示例放 `docs/coding/` 或 `docs/ai-collab/`
3. **AI 不擅自改 AGENTS.md** — 本文件需要项目所有者确认
4. **所有改动可追溯** — 引用文件路径 + 行号 + 需求来源
5. **诚实优先** — 不确定直说"不知道 / 需实测"，禁止编造

## 二、上下文管理

### 2.1 新对话开始时

AI 应主动询问或自行确认的项目背景（最少信息包）：
- 当前在哪个模块工作（contract / consultation / knowledge-base / ops）
- 当前任务的输入输出是什么
- 涉及哪些 docs/ 子文档

### 2.2 长任务中途

每完成一个里程碑，要求 AI 输出：
- 做了什么
- 改了哪些文件（路径列表）
- 下一步建议

### 2.3 切换 AI 时

将本目录（`docs/ai-collab/`）作为上下文交接包，新 AI 必须读完才能动手。

## 三、Prompt 模板

详见 `docs/ai-collab/prompt-templates.md`（待补）。

核心模板：
- **新功能开发模板**
- **Bug 修复模板**
- **代码审查模板**
- **文档撰写模板**
- **架构决策讨论模板**

## 四、AI 输出规范

### 4.1 代码改动
- 输出必须含：**文件路径 + 关键 diff + 改动原因**
- 涉及架构变更：先更新 docs/architecture/，再改代码

### 4.2 文档撰写
- 不重复 AGENTS.md 已有的内容
- 用清晰的章节结构，避免大段无序列表
- 中文优先，关键术语保留英文

### 4.3 决策建议
- 给方案时必须列出：**至少 2 个备选 + 各自的优劣 + 推荐 + 理由**
- 不确定的事标注"需实测"或"需查阅"

## 五、禁止事项

- ❌ AI 自行修改 AGENTS.md
- ❌ AI 在没有上下文时假设需求
- ❌ AI 编造 API、价格、库版本号
- ❌ AI 在 docs/ 之外的位置写文档
- ❌ AI 跳过 AGENTS.md 直接动手改架构

## 六、AI 自检清单（任务结束前自查）

- [ ] 所有文件改动是否标注了路径？
- [ ] 是否遵守了 AGENTS.md 8 条核心原则？
- [ ] 是否更新了相关 docs/ 子文档（如架构变更）？
- [ ] 是否有不确定的事标注了"需实测"？
- [ ] 是否给了"下一步建议"？
