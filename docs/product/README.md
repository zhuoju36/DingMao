## 一、产品一句话定义

面向设计院、监理、咨询机构的工程技术人员，提供"建工法律顾问"式的对话工作台，覆盖**合同审查**与**施工变更扯皮**两个高频场景，产出可直接使用的法律文书与可追溯的项目档案。

## 二、目标用户

| 用户类型 | 典型岗位 | 核心痛点 |
|---|---|---|
| 设计院 | 设计工程师、所长助理 | 图纸变更责任界定、合同审查 |
| 监理公司 | 总监理工程师、专业监理 | 签证必要性判断、事故责任评估 |
| 咨询机构 | 造价工程师、招标代理 | 招投标合规、索赔证据梳理 |

**非目标用户**：建工执业律师（律师需要的是类案检索+文书生成工具，与本产品形态不同）。

## 三、MVP 范围（红线）

### 3.1 必做场景

1. **合同审查场景** — 用户上传合同/招标文件，AI 出具红/黄/绿分级审查报告
2. **变更扯皮场景** — 律师问诊式多轮对话，产出签证单/索赔报告/证据目录

### 3.2 应用场景全景（含 V2/V3）

| 场景 | 优先级 | MVP? | 主要用户 | 关键能力 |
|---|---|---|---|---|
| 合同审查 | P0 | ✅ | 造价/监理/施工 | 风险分级 + 文书 |
| 变更扯皮 | P0 | ✅ | 监理/施工/造价 | 多轮问诊 + 签证/索赔 |
| 强条速查 | P1 | V2 | 全员（尤其中员） | 一键查 GB + 行为映射 |
| 事故责任初评 | P1 | V2 | 监理/施工 | 责任方 + 比例 + 证据 |
| 招投标合规 | P1 | V3 | 招标代理 | 标书条款审查 + 废标风险 |
| 质保期管理 | P2 | V3 | 监理/施工 | 缺陷记录 + 保修金 |
| 决算争议 | P2 | V3 | 造价/施工 | 审计争议 + 送审 |

**完整信息架构（含 URL 路由、组件清单、UX 原则）见 [`docs/product/ia.md`](./ia.md)**。

### 3.2 必做能力

| 能力 | 说明 |
|---|---|
| 律师问诊对话 | 结构化多轮事实采集，禁止自由提问 |
| 三源证据结论 | 🟦 事实 + 🟨 法条 + 🟥 强条；缺失则降级结论等级 |
| 红黄绿分级 | 🔴 红线（明确违法/无效）、🟡 黄区（风险高）、🟢 可控 |
| 文书起草 | 5 类：签证单、索赔报告、监理通知单、工作联系单、审查意见备忘录 |
| 项目档案 | 单用户单项目，跨场景复用（合同审查 → 变更扯皮自动带入） |
| 前置免责声明 | 每次关键输出顶部固定显示 |

### 3.3 MVP 不做（明确边界）

- ❌ 推荐性国家标准（仅强条入库）
- ❌ 第三方软件对接（广联达、品茗、新点等）
- ❌ 多用户协作（项目组共用档案）
- ❌ 模拟对方立场（角色只做视角差异）
- ❌ 增值服务层（人工律师复核）
- ❌ 复杂在线文书编辑器（用 Word 模板下载代替）
- ❌ 涉外工程 / 港澳台法律

## 四、核心原则（与 AGENTS.md 一致）

1. 数据确凿优先
2. LLM 不生成关键数字（金额/时间/条款号/版本号）
3. 法条/强条引用必须有版本号 + 生效日期
4. 文书前必须显示免责
5. MVP 12 周红线
