# 知识库

> MVP 阶段知识库原始数据 + 结构化脚本。与代码解耦，可重建。

---

## 目录

```
knowledge-base/
├── laws/         # 法律法规原始 PDF / 文本
├── standards/    # 国家强制性标准 PDF（38 本通用规范）
├── mappings/     # 行为-强条映射（人工标注 + AI 校验）
└── scripts/      # 结构化脚本（PDF 解析、字段映射、入库）
```

## 入库范围（MVP 边界）

### 法律法规（50 部核心）
- 民法典合同编建工专节
- 建设工程质量管理条例、安全生产管理条例
- 招标投标法、政府采购法及实施条例
- 建设工程价款结算暂行办法
- 各省高院建工纠纷裁判指引（5-8 个建工大省）
- 建设工程施工合同（示范文本）GF-2017-0201

### 国家强制性标准（38 本通用规范全文强条）
通用规范 GB 55001-2022 系列全部 38 本，已在住建部官网全文公开。

### 不入库（MVP 明确边界）
- ❌ 推荐性国家标准
- ❌ 通用规范以外的其他专项规范
- ❌ 行业标准 / 地方标准 / 团体标准

## 数据流转

```
原始数据 (laws/, standards/)
       ↓
结构化脚本 (scripts/)  - pdfplumber + PyMuPDF + 人工校对
       ↓
结构化结果 (JSON)
       ↓
应用层加载 (app/knowledge/) - 启动时导入数据库
```

## 行为-强条映射（核心差异化）

这是本产品最有价值的资产之一，必须人工主导：

| 文件 | 说明 |
|---|---|
| `mappings/behavior_standard.json` | 主映射表 |
| `mappings/annotations/` | 标注记录 |

标注流程见 `docs/domain/knowledge-base.md`（待补）。

## 重建说明

按 AGENTS.md 核心原则第 7 条，**知识库必须可重建**：
- 原始数据有备份
- 结构化脚本在 Git 中
- 应用层有 idempotent 导入逻辑

如果容器丢失，可一键从 `laws/` + `standards/` + `scripts/` 重建。
